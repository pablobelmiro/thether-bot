Código abierto · para Claude Code

Deja tu equipo encendido. Sigue trabajando desde tu teléfono.

Tether es un bot de Telegram y un panel web para las sesiones de Claude Code que se ejecutan en tu propio equipo. Envía prompts, lee respuestas, aprueba acciones y cambia de proyecto desde cualquier lugar.

Empezar GitHub

Licencia MIT · Linux y macOS · Sin clave de API · Funciona en 127.0.0.1

Qué hace

Dos formas de entrar. Las mismas sesiones.

Tether conecta la CLI de Claude Code de tu equipo con Telegram y con un panel en el navegador. Cada sesión es un proceso claude normal dentro de tmux, así que puedes hacer tmux attach cuando quieras.

Telegram, en tu teléfono

  • Habla con cualquier sesión y cambia entre ellas.
  • Recibe las respuestas de Claude en cuanto terminan.
  • Responde a sus preguntas y aprueba permisos con botones.
  • Envía fotos y archivos.
  • Reanuda conversaciones antiguas o abre una sesión nueva en cualquier carpeta.

Un panel, en tu navegador

  • Todas las sesiones, con chat completo y adjuntos.
  • Comandos slash y cambio de modelo / esfuerzo.
  • Gráficos de contexto y de límites del plan.
  • Una vista de la terminal en vivo.
Cómo funciona

Un solo proceso en tu equipo.

Tether es un único proceso de Node que escucha en 127.0.0.1:4100. Ejecuta Claude Code en tmux y lee lo que Claude Code ya escribe: eventos de hooks, transcripciones y la línea de estado.

Telegramtu teléfono
Navegadorpanel
→↓
Tether127.0.0.1:4100
→↓
tmuxuno por sesión
→↓
claudetu sesión iniciada

El bot usa long polling, así que no se abre ningún puerto a internet. El panel solo escucha en localhost.

  1. Envías un mensaje

    Desde Telegram o desde el panel. Se pega en la ventana de tmux de la sesión activa, como si lo escribieras en la terminal.

  2. Claude trabaja

    Los hooks le cuentan a Tether lo que pasa. Las preguntas y las solicitudes de permiso te llegan con botones.

  3. La respuesta vuelve

    Cuando termina el turno, la respuesta final se lee de la propia transcripción de Claude Code y se te envía.

Funciones

Todo lo que necesitas lejos del escritorio.

01

Muchas sesiones

Ejecuta un Claude por proyecto y cambia con /cambiar. Las respuestas de las otras sesiones esperan en una bandeja 📬.

02

Nueva sesión desde una ruta

/nueva ~/proyectos/mi-app abre Claude en cualquier carpeta. El diálogo del panel autocompleta las rutas.

03

Reanuda lo que sea

Retoma cualquier conversación reciente de Claude Code de este equipo, incluso las que empezaste en la terminal.

04

Botones para decidir

Las preguntas y las solicitudes de permiso se convierten en botones. Responde en un sitio y los demás se actualizan.

05

Fotos y archivos

Envía una captura desde el teléfono o arrastra archivos al panel. El pie de foto se convierte en el prompt.

06

Modelo y esfuerzo

Cambia entre Opus, Sonnet, Haiku y otros, y ajusta el esfuerzo de razonamiento, desde cualquiera de los dos lados.

07

Consumo de un vistazo

Límites del plan de 5 horas y 7 días con la hora de reinicio, contexto por sesión y coste, en gráficos y en /usage.

08

Terminal en vivo

Mira exactamente lo que hay en pantalla desde el panel, o pide una captura con /pantalla.

09

Tres idiomas

Bot y panel en English, Português y Español. Añadir un idioma es copiar una carpeta.

Modos de permiso

Tú decides cuánto puede hacer Claude por su cuenta.

Cada sesión se ejecuta en uno de tres modos, que eliges al crearla o reanudarla.

Preguntar

Preguntar

Cada solicitud de permiso llega a Telegram y al panel con botones. Responde desde donde quieras; los demás sitios se actualizan.

Ideal para carpetas sensibles o cuando quieres ver cada paso.

Auto · recomendado

Auto

Claude trabaja por su cuenta y el clasificador de seguridad integrado en Claude Code revisa cada acción. Las arriesgadas se bloquean, incluidas las provocadas por inyección de prompts.

El modo adecuado para la mayor parte del trabajo que lanzas desde el teléfono.

Omitir

Omitir

Claude se ejecuta con --dangerously-skip-permissions y nunca pregunta. Nadie revisa sus acciones.

Solo para carpetas y trabajos de confianza que puedas deshacer.

Seguridad

Protegido desde el primer momento.

Tether puede hacer que Claude ejecute comandos en tu equipo, así que pone varias barreras delante.

  • Acceso al bot

    Un usuario de Telegram necesita su propio número en tu lista de permitidos y la contraseña. El bot se vuelve a bloquear tras un tiempo de inactividad (12 h por defecto) y en cada reinicio.

  • Nunca sin protección

    El bot se niega a arrancar sin contraseña y sin al menos un número permitido. El último número no se puede eliminar.

  • Solo local

    El panel escucha en 127.0.0.1 y pide la misma contraseña. Las comprobaciones de Host y Origin bloquean el DNS rebinding y las peticiones entre sitios.

  • Secretos en reposo

    La contraseña se guarda con scrypt. El token del bot se cifra con AES-256-GCM usando una clave local (modo 600).

  • Fuera del alcance de Claude

    tether setup añade reglas de denegación de Claude Code para que Claude no pueda leer ni editar ~/.tether ni ~/.ssh.

  • Registro de auditoría

    Cada inicio de sesión, desbloqueo, cambio de configuración y respuesta a un permiso queda registrado y visible en el panel.

Inicio rápido

Funcionando en pocos minutos.

Necesitas Linux o macOS, Node.js 22.13+, tmux, curl y Claude Code instalado y con la sesión iniciada.

Terminal
$ git clone https://github.com/pablobelmiro/thether-bot.git && cd thether-bot && ./install.sh

Después abre http://127.0.0.1:4100 y sigue el asistente inicial. El manual explica cada paso, incluida la creación de tu bot de Telegram.

Preguntas frecuentes

Preguntas.

¿Se comparte mi cuenta de Claude con alguien?

No. Tether usa tu sesión local de claude, la misma que usas en la terminal. Nada pasa por terceros: el bot solo habla con Telegram, y el panel solo con tu propio equipo.

¿Necesito una clave de API?

No. Las sesiones ejecutan la CLI normal de Claude Code con tu suscripción o tu sesión actual. No hay ninguna clave que configurar.

¿Pueden usar mi bot otras personas?

No. Cualquiera puede encontrar el nombre de usuario de un bot, pero Tether solo responde a cuentas de Telegram que compartan su propio contacto con un número de tu lista de permitidos, y después pide tu contraseña. Los demás solo ven la petición de "compartir contacto".

¿Mi equipo tiene que estar encendido?

Sí. Claude se ejecuta en tu equipo, así que tiene que estar encendido y sin suspender. En Linux, el instalador puede configurar Tether como un servicio en segundo plano que arranca solo.

¿Puedo seguir usando la terminal?

Sí. Cada sesión es una sesión normal de tmux, así que tmux attach funciona en cualquier momento. Lo que escribas allí también aparece en el chat del panel. Incluso puedes adoptar una sesión de tmux que hayas abierto tú.

¿Es un producto oficial de Anthropic?

No. Tether es un proyecto comunitario independiente, publicado con licencia MIT.
