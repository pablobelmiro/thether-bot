Código aberto · para o Claude Code

Deixe o computador ligado. Continue trabalhando pelo celular.

O Tether é um bot do Telegram e um painel web para as sessões do Claude Code que rodam na sua própria máquina. Envie prompts, leia respostas, aprove ações e troque de projeto de qualquer lugar.

Começar GitHub

Licença MIT · Linux e macOS · Sem chave de API · Roda em 127.0.0.1

O que ele faz

Duas entradas. As mesmas sessões.

O Tether conecta o Claude Code CLI do seu computador ao Telegram e a um painel no navegador. Cada sessão é um processo claude normal dentro do tmux, então você continua podendo usar tmux attach a qualquer momento.

Telegram, no celular

  • Converse com qualquer sessão e alterne entre diretórios de trabalho.
  • Receba as respostas do Claude assim que ficam prontas.
  • Responda às perguntas dele e aprove permissões com botões.
  • Envie fotos e arquivos.
  • Retome conversas antigas ou abra uma nova sessão em qualquer pasta.

Um painel, no navegador

  • Todas as sessões, agrupadas por diretório de trabalho, com chat completo e anexos.
  • Comandos de barra e troca de modelo e esforço.
  • Gráficos de contexto e dos limites do plano.
  • Visualização do terminal ao vivo.
Como funciona

Um único processo na sua máquina.

O Tether é um único processo Node escutando em 127.0.0.1:4100. Ele roda o Claude Code no tmux e lê o que o próprio Claude Code já grava: eventos de hooks, transcrições e a linha de status.

O bot usa long polling, então nenhuma porta é aberta para a internet. O painel só escuta em localhost.

  1. Você envia uma mensagem

    Pelo Telegram ou pelo painel. Ela é colada na janela do tmux da sessão ativa, como se você digitasse no terminal.

  2. O Claude trabalha

    Os hooks avisam o Tether do que está acontecendo. Perguntas e pedidos de permissão chegam até você com botões.

  3. A resposta volta

    Quando o turno termina, a resposta final é lida da própria transcrição do Claude Code e enviada para você.

Recursos

Tudo o que você precisa longe da mesa.

01

Diretórios de trabalho

As sessões ficam agrupadas por pasta, com quantos Claudes você quiser em cada uma. Alterne com /trocar e veja as sessões da pasta com /sessoes. As outras respostas esperam numa caixa de entrada 📬.

02

Nova sessão a partir de um caminho

/nova ~/projetos/meu-app abre o Claude em qualquer pasta. A janela do painel completa os caminhos automaticamente.

03

Pause e retome

Pause uma sessão ociosa com /pausar para liberar memória e retome a mesma conversa depois. Ou continue qualquer conversa recente do Claude Code, mesmo as que começaram no terminal.

04

Botões para decidir

Perguntas e pedidos de permissão viram botões. Responda em um lugar e os outros se atualizam.

05

Fotos e arquivos

Mande um print do celular ou arraste arquivos para o painel. A legenda vira o prompt.

06

Modelo e esforço

Troque entre Opus, Sonnet, Haiku e outros, e ajuste o esforço de raciocínio, de qualquer um dos lados.

07

Uso num relance

Limites do plano de 5 horas e de 7 dias com horário de renovação, contexto por sessão e custo, em gráficos e no /usage.

08

Terminal ao vivo

Veja exatamente o que está na tela pelo painel, ou peça uma captura com /tela.

09

Três idiomas

Bot e painel em English, Português e Español. Adicionar um idioma é copiar uma pasta.

10

Tarefas agendadas

Execute um prompt automaticamente — a cada N minutos ou nos dias da semana e horário que você escolher. Cada execução cria uma sessão descartável do Claude, injeta o prompt e entrega o resultado para um número do Telegram. Se a execução anterior ainda estiver em andamento, a nova é ignorada em vez de duplicada.

Modos de permissão

Você decide quanto o Claude pode fazer sozinho.

Cada sessão roda em um de três modos, escolhido ao criá-la ou retomá-la.

Perguntar

Perguntar

Todo pedido de permissão vai para o Telegram e para o painel com botões. Responda de onde estiver; os outros lugares se atualizam.

Ideal para pastas sensíveis, ou quando você quer ver cada passo.

Auto · recomendado

Auto

O Claude trabalha sozinho, e o classificador de segurança embutido no Claude Code revisa cada ação. As arriscadas são bloqueadas, inclusive as induzidas por prompt injection.

O padrão certo para a maior parte do trabalho que você inicia pelo celular.

Ignorar

Ignorar

O Claude roda com --dangerously-skip-permissions e nunca pergunta. Nada revisa as ações dele.

Só para pastas e trabalhos em que você confia e que consegue desfazer.

Segurança

Protegido por padrão.

O Tether pode fazer o Claude rodar comandos no seu computador, por isso coloca várias barreiras na frente disso.

  • Acesso ao bot

    Um usuário do Telegram precisa ter o próprio número na sua lista de autorizados e a senha. O bot volta a travar depois de um tempo sem uso (12 h por padrão) e a cada reinício.

  • Não roda desprotegido

    O bot se recusa a iniciar sem uma senha e pelo menos um número autorizado. O último número não pode ser removido.

  • Só local

    O painel escuta em 127.0.0.1 e pede a mesma senha. Verificações de Host e Origin bloqueiam DNS rebinding e requisições de outros sites.

  • Segredos guardados

    A senha é armazenada com scrypt. O token do bot é criptografado com AES-256-GCM usando uma chave local (modo 600).

  • Fora do alcance das ferramentas do Claude

    O tether setup adiciona regras de bloqueio (deny) ao Claude Code para que as ferramentas de arquivo do Claude não possam ler nem editar ~/.tether ou ~/.ssh. Para comandos de terminal também, ative o sandbox do Claude Code (/sandbox); sem ele, a barreira é o classificador do modo Auto.

  • Registro de auditoria

    Todo login, desbloqueio, mudança de configuração e resposta de permissão fica registrado e visível no painel.

Início rápido

Funcionando em poucos minutos.

Você precisa de Linux ou macOS, Node.js 22.13+, tmux, curl e do Claude Code instalado e com login feito.

Terminal
$ git clone https://github.com/pablobelmiro/thether-bot.git && cd thether-bot && ./install.sh

Depois abra http://127.0.0.1:4100 e siga o assistente de primeira execução. O manual mostra cada passo, inclusive como criar o seu bot do Telegram.

Perguntas frequentes

Dúvidas.

Minha conta do Claude é compartilhada com alguém?

Não. O Tether usa o seu login local do claude, o mesmo que você usa no terminal. Nada passa por terceiros; o bot só conversa com o Telegram, e o painel só com a sua própria máquina.

Preciso de uma chave de API?

Não. As sessões rodam o Claude Code CLI normal, com a sua assinatura ou login atual. Não há chave para configurar.

Estranhos podem usar o meu bot?

Não. Qualquer pessoa pode achar o nome de usuário de um bot, mas o Tether só responde a contas do Telegram que compartilham o próprio contato com um número da sua lista de autorizados, e depois ainda pede a sua senha. Todo o resto só vê o pedido para compartilhar o contato.

O computador precisa ficar ligado?

Sim. O Claude roda na sua máquina, então ela precisa estar ligada e acordada. No Linux, o instalador pode configurar o Tether como um serviço em segundo plano que inicia sozinho; reiniciá-lo não derruba as suas sessões.

Ainda posso usar o terminal?

Pode. Cada sessão é uma sessão normal do tmux, então tmux attach funciona a qualquer momento. O que você digita lá também aparece no chat do painel. Dá até para adotar uma sessão do tmux que você mesmo iniciou.

Este é um produto oficial da Anthropic?

Não. O Tether é um projeto independente da comunidade, publicado sob a licença MIT.
