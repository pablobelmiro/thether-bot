Leave your computer on. Keep working from your phone.

Tether is a Telegram bot and a web dashboard for the Claude Code sessions running on your own machine. Send prompts, read answers, approve actions and switch projects from anywhere.

Get started GitHub

MIT license · Linux & macOS · No API key · Runs on 127.0.0.1

What it does

Two ways in. Same sessions.

Tether connects the Claude Code CLI on your computer to Telegram and to a browser dashboard. Each session is a normal claude process inside tmux, so you can still tmux attach to it at any time.

Telegram, on your phone

  • Talk to any session and switch between working directories.
  • Receive Claude's answers as they finish.
  • Answer its questions and approve permissions with buttons.
  • Send photos and files.
  • Resume old conversations, or start a new session in any folder.

A dashboard, in your browser

  • Every session, grouped by working directory, with a full chat and attachments.
  • Slash commands and model / effort switching.
  • Context and plan-limit charts.
  • A live terminal view.
How it works

One process on your machine.

Tether is a single Node process listening on 127.0.0.1:4100. It runs Claude Code in tmux and reads what Claude Code already writes: hook events, transcripts and the status line.

The bot uses long polling, so no port is opened to the internet. The dashboard only listens on localhost.

  1. You send a message

    From Telegram or the dashboard. It's pasted into the active session's tmux pane, like typing in the terminal.

  2. Claude works

    Hooks tell Tether what's happening. Questions and permission prompts reach you with buttons.

  3. The answer comes back

    When the turn ends, the final answer is read from Claude Code's own transcript and sent to you.

Features

Everything you need away from the desk.

01

Working directories

Sessions are grouped by folder, with as many Claudes per folder as you like. Switch with /change, list a folder's sessions with /sessions. Other answers wait in a 📬 inbox.

02

New session from a path

/new ~/projects/my-app opens Claude in any folder. The dashboard dialog autocompletes paths.

03

Pause and resume

Pause an idle session with /pause to free memory, then resume the same conversation later. Or pick up any recent Claude Code conversation, even ones started in the terminal.

04

Buttons for decisions

Questions and permission prompts become buttons. Answer in one place and the others update.

05

Photos and files

Send a screenshot from your phone or drag files into the dashboard. The caption becomes the prompt.

06

Model and effort

Switch between Opus, Sonnet, Haiku and others, and set the reasoning effort, from either side.

07

Usage at a glance

5-hour and 7-day plan limits with reset times, context per session and cost, in charts and in /usage.

08

Live terminal

See exactly what's on screen in the dashboard, or get a snapshot with /screen.

09

Three languages

Bot and dashboard in English, Português and Español. Adding a language is copying one folder.

10

Scheduled tasks

Run a prompt on a timer — every N minutes or on chosen weekdays at a set time. Each run creates a disposable Claude session, injects the prompt, and delivers the result to one Telegram number. Overlap protection ensures a schedule never runs twice at once.

Permission modes

You choose how much Claude can do alone.

Every session runs in one of three modes, picked when you create or resume it.

Ask

Ask

Every permission prompt goes to Telegram and the dashboard with buttons. Answer from anywhere; the other places update.

Best for sensitive folders, or when you want to see each step.

Auto · recommended

Auto

Claude works on its own, and Claude Code's built-in safety classifier reviews each action. Risky ones are blocked, including actions pushed by prompt injection.

The right default for most work you start from your phone.

Bypass

Bypass

Claude runs with --dangerously-skip-permissions and never asks. Nothing reviews its actions.

Only for folders and work you trust and can undo.

Security

Locked down by default.

Tether can make Claude run commands on your computer, so it puts several barriers in front of that.

  • Bot access

    A Telegram user needs their own phone number on your allow list and the password. The bot locks again after an idle time (12 h by default) and on every restart.

  • Can't run unprotected

    The bot refuses to start without a password and at least one allowed number. The last number can't be removed.

  • Local only

    The dashboard listens on 127.0.0.1 and needs the same password. Host and Origin checks block DNS rebinding and cross-site requests.

  • Secrets at rest

    The password is hashed with scrypt. The bot token is encrypted with AES-256-GCM using a local key (mode 600).

  • Off-limits to Claude's file tools

    tether setup adds Claude Code deny rules so Claude's file tools can't read or edit ~/.tether or ~/.ssh. For shell commands too, turn on Claude Code's sandbox (/sandbox); otherwise Auto mode's classifier is the barrier.

  • Audit log

    Every login, unlock, configuration change and permission answer is recorded and visible in the dashboard.

Quick start

Running in a few minutes.

You need Linux or macOS, Node.js 22.13+, tmux, curl and Claude Code installed and logged in.

Terminal
$ git clone https://github.com/pablobelmiro/thether-bot.git && cd thether-bot && ./install.sh

Then open http://127.0.0.1:4100 and follow the first-run wizard. The manual walks through every step, including creating your Telegram bot.

FAQ

Questions.

Is my Claude account shared with anyone?

No. Tether uses your local claude login, the same one you use in the terminal. Nothing is proxied to a third party; the bot talks only to Telegram, and the dashboard only to your own machine.

Do I need an API key?

No. Sessions run the regular Claude Code CLI with your existing subscription or login. There's no key to configure.

Can strangers use my bot?

No. Anyone can find a bot's username, but Tether only answers Telegram accounts that share their own contact with a number on your allow list, and then asks for your password. Everyone else only sees the "share contact" prompt.

Does my computer need to stay on?

Yes. Claude runs on your machine, so it has to be on and awake. On Linux the installer can set Tether up as a background service that starts automatically; restarting it doesn't stop your sessions.

Can I still use the terminal?

Yes. Each session is a normal tmux session, so tmux attach works at any time. Messages typed there also show up in the dashboard chat. You can even adopt a tmux session you started yourself.

Is this an official Anthropic product?

No. Tether is an independent community project, released under the MIT license.
